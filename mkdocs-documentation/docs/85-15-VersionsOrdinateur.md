# Pourquoi utiliser e-carnet sur ordinateur ?

Bien que l'application e-carnet soit principalement conçue pour un usage mobile sur tablette (Android/iPad), les versions pour ordinateur (Windows, macOS, Linux) offrent des avantages significatifs pour les enseignants.

## Les avantages de la version ordinateur

- **Confort de saisie** : Utiliser un véritable clavier permet de rédiger des commentaires plus détaillés et plus rapidement.
- **Gestion des médias** : Il est plus facile de trier, renommer ou importer des photos et vidéos depuis un ordinateur.
- **Performance** : Les ordinateurs disposent généralement de plus de puissance pour générer les e-carnets complexes ou gérer des centaines de fichiers.
- **Sauvegarde** : Vous pouvez facilement copier vos sauvegardes sur un disque externe ou un service de stockage en ligne.

## Fonctionnement identique

L'application sur ordinateur est strictement identique à celle sur tablette. Vous y retrouverez :

- Le même catalogue d'observables.
- La même interface de gestion des élèves.
- Les mêmes outils de génération de documents.

## Synchronisation entre appareils

Il n'y a pas de synchronisation automatique par Internet (pour garantir votre confidentialité). Le transfert de données entre votre tablette et votre ordinateur se fait simplement par le biais de la fonction **Sauvegarde / Restauration**.

1.  Faites une sauvegarde sur votre tablette.
2.  Copiez le fichier `SAUVEGARDE_ECM.zip` sur votre ordinateur.
3.  Utilisez la fonction **Restaurer** sur la version ordinateur.

Vous pouvez ainsi commencer à prendre des photos en classe avec votre tablette, puis terminer la rédaction des bilans confortablement installé devant votre ordinateur !
