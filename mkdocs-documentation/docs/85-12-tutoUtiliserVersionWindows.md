# Utiliser la version Windows

L'application e-carnet est disponible en version installable pour Windows. Cette version permet de gérer vos élèves, médias et e-carnets directement depuis votre ordinateur.

!!! warning "Avertissement"

Parceque cette version n'est pas encore "signée" et que le développeur n'est pas encore connu de Microsoft, de multiples alertes de sécurité vont être affichées par Windows:

- au moment du téléchargement (confirmer)
- au moment de l'installation

Il faut confirmer et accepter de continuer partout où cela sera proposé.

## Téléchargement

[🚀 Télécharger la version 2.3.8 pour Windows](https://tja-solutions.com/RELEASES/WINDOWS/e-carnet%20Setup%202.3.8.exe)

## Installation

0. Commencer par créer un nouveau dossier "e-carnet" dans votre dossier "Documents", vous pourrez ainsi le sélectionner au démarrage de l'application.
1. Téléchargez le fichier `.exe` ci-dessus.
2. Lancez l'installateur et suivez les instructions. Si vous ne l'avez pas fait, vous devrez créer un nouveau dossier, par exemple "e-carnet" puis le sélectionner.

## Premier lancement

Lors du premier lancement, l'application est vide. Vous pouvez :

- Créer manuellement vos élèves.
- Importer un fichier Excel de vos élèves.
- Restaurer une sauvegarde provenant d'une tablette ou d'une autre installation.

## Avantages de la version PC

- Confort de saisie avec le clavier.
- Gestion facilitée des gros volumes de médias.
- Génération plus rapide des e-carnets en PDF.
- Sauvegarde locale simplifiée.

## Repasser sur tablette : importer sauvegarde

Pour transférer vos données vers une tablette :

1. Effectuez une sauvegarde complète depuis les réglages.
2. Transférez le fichier `SAUVEGARDE_ECM.zip` sur votre tablette.
3. Utilisez la fonction "Restaurer une sauvegarde" sur la tablette.
